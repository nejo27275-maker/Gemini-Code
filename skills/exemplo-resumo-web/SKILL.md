# Resumo de conteúdo web

Ao resumir uma página ou artigo:

1. Leia o conteúdo completo antes de resumir (use `read_file` se já foi baixado, ou peça a URL).
2. Escreva 3 a 5 frases no máximo, sem copiar trechos literais — sempre com suas próprias palavras.
3. Comece pela informação mais importante (o quê aconteceu / do que se trata).
4. Se houver números, datas ou nomes próprios importantes, mantenha-os exatos.
5. Termine indicando, em uma frase, por que isso importa ou o que muda a partir disso.
6. Nunca invente fatos que não estão no texto original.
